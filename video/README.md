# Código del video

Las instrucciones para instalar, editar, renderizar y comprobar el proyecto
están en el [README principal](../README.md).

Las nueve escenas se componen en `AndesminVideo.tsx`. Los tiempos y colores
están centralizados en `videoConfig.ts`, la selección de medios en `assets.ts`
y los elementos reutilizables en `components/`.
